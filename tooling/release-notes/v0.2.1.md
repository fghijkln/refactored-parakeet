Parakeet v0.2.1 — deep customization of [dsh-Go](https://github.com/ccch1mneyyy/dsh-go) by [ccch1mneyyy](https://github.com/ccch1mneyyy) (AGPL-3.0, upstream ccch1mneyyy/dsh-Go@cf2f7c8; changes listed in PARAKEET_NOTICE.md). Not an official DSH Go build.

Changes in 0.2.1: the engine no longer dies at startup on phones that also have Termux installed (`OpenSSL configuration error ... openssl.cnf: Permission denied`). Termux's node/bash have Termux's /data/data/com.termux/files/usr paths compiled in; the app now gives OpenSSL its own config, modules/engines dirs and a CA bundle built from Android's system certificates, and its node/bash/sh wrappers default HOME, TMPDIR, LD_LIBRARY_PATH and these settings for child processes. The emulator smoke now plants an unreadable Termux tree and starts the app's own engine.

* `parakeet-v0.2.1-en-arm64-v8a.apk` — English-only build (arm64 phones)

- Host runtime: DeepSeek Harness on Termux's Bionic node + bash, shipped unmodified as native libs; no Ubuntu, no PRoot.
- root_shell / root_status tools through su (KernelSU), behind DSH's approval prompt; device-destroying commands are always confirmed.
- Removed: feedback, DeepSeek account sign-in, telemetry/usage statistics, update checks, star prompt, forum/community, share links.
- Separate pure-Chinese and pure-English APKs; /sdcard can be chosen as a workspace.
- Known gap: in the English APK, agent-facing text that upstream writes in Chinese only (the bundled dsh-go-ui / dsh-go-plugin / dsh-go-support skills, the phone-control tool descriptions and results, the AGENTS.md section and safe-mode report) is still Chinese; the app UI and the user guide skill are English.
