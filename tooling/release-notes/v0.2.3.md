Parakeet v0.2.3 — deep customization of [dsh-Go](https://github.com/ccch1mneyyy/dsh-go) by [ccch1mneyyy](https://github.com/ccch1mneyyy) (AGPL-3.0, upstream ccch1mneyyy/dsh-Go@cf2f7c8; changes listed in PARAKEET_NOTICE.md). Not an official DSH Go build.

Changes in 0.2.3: **Phone control works on the host engine.** In 0.2.2 the agent's phone tools (`mcp__phone__*`) never connected on a real phone: the engine runs on Android's own `/`, and the phone MCP server was handed the in-runtime path `/var/lib/dsh-app/phone/bridge.json`, which does not exist there, so its relay exited with ENOENT while Settings showed everything green. Now the app writes host paths into the phone (and message-search) overlay under the host engine, the runtime maps runtime-tree guest paths in every child's arguments and environment (never Android's own /system, /data, /sdcard, /storage, /proc), and the relay falls back to its own tree. Phone control's status line and the diagnostics now report whether the MCP server really connected (or why not) instead of only the switch, accessibility and bridge. Root mode (0.2.2) is unchanged.

- Removed: feedback, DeepSeek account sign-in, telemetry/usage statistics, update checks, star prompt, forum/community, share links.
- Separate pure-Chinese and pure-English APKs; /sdcard can be chosen as a workspace.
- Known gap: in the English APK, agent-facing text that upstream writes in Chinese only (the bundled dsh-go-ui / dsh-go-plugin / dsh-go-support skills, the phone-control tool descriptions and results, the AGENTS.md section and safe-mode report) is still Chinese; the app UI and the user guide skill are English.
